clearance-central

central server for clearance, an scp: secret laboratory plugin that scores joining players from their steam account and rejects alts + banned accounts.

servers running it share anonymous daily stats and ban reports here. it returns facts only, never verdicts: each server decides what they mean.

not affiliated with northwood studios.
